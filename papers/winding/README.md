# Circular colourings of abelian Cayley graphs below four come from characters

[`winding.pdf`](winding.pdf) is a twelve-page draft (3 and 4 October 2026):

- **Theorem 1 (Theorem W⁺).** For `p/q < 4`, a Cayley graph of an abelian group maps to the circular clique
  `K_{p/q}` if and only if some character maps every generator into `[q/p, 1 − q/p]`. So its circular chromatic
  number, when it is less than 4, is `1/κ(S)`, and 4 is sharp (`K₄`). In particular the graph is 3-colourable if and
  only if some character maps every generator into `[1/3, 2/3]`, and it maps to `C_{2k+1}` if and only if some
  character maps the generators into `[k/(2k+1), (k+1)/(2k+1)]` (Theorem W). The proof lifts a colouring to
  integers in `[q, p − q]` on the edges; for `p < 4q` squares do not wind (the discrete winding number of Krebs and
  Sankar for three colours, and of Brewster, McGuinness, Moore and Noel and Brewster and Moore below 4); averaging
  the lifts over the group with an invariant mean (the new step) gives the character.
- **Corollaries.** Every set of Bohr recurrence is a set of 3-chromatic recurrence (the three-colour case of
  Katznelson's question): for every 3-colouring of `ℕ`, the union of the difference sets of the classes contains
  `{n : ‖nα‖ < 1/3}` for some `α`, which answers Question 3 of Glasscock, Koutsogiannis and Richter (Bull. Amer.
  Math. Soc. 2022); `χ_c(G(ℤ, D)) = 1/κ(D)` and `χ(G(ℤ, D)) = ⌈1/κ(D)⌉` for every set `D` of three distances, which
  answers Problem 3 of Liu's survey on distance graphs (Taiwanese J. Math. 2008); Cayley graphs of finitely
  generated abelian groups with finite connection sets and `χ_c < 4` have periodic optimal circular colourings, and
  `χ_c < 4` is decidable, while for many colours (Greenfeld and Tao's aperiodic tilings) periodicity fails; no Cayley
  graph of an abelian group of exponent 2 or 4 has `2 < χ_c < 4` (a uniform proof of known facts, which contains Payan's
  theorem and the exponent-4 case of Krebs and Sankar); for planes over a number field, 3-colourability is a question about characters of the
  group generated by the unit vectors.
- **Theorem 12.** `χ(ℚ(√d)²) = 4` for `d = 83, 107, 203`, `4 ≤ χ(ℚ(√143)²) ≤ 5` and `χ(ℚ(√167)²) ≥ 4`, by exact
  branch-and-bound certificates (`data/quadratic_planes/winding/`, checked by `check_w.py`), for fields where no
  finite non-3-colourable graph had been found.
- **Finite witnesses (Section 7, added 4 October).** For a finite connection set with `2 < χ_c < 4`, every
  homomorphism to `K_{χ_c}` has a tight cycle (an optimal character has a nonnegative relation among the generators
  where it is tight, or it could be perturbed), so `χ_c` is attained by a finite subgraph; for example the segment
  `{0, …, 18}` of the distance graph with distances 3, 4, 9, 12 (`χ_c = 7/2`; SAT, not certified). Refereed inside
  the project, with the corollary on planes over number fields of `papers/three-colours/` that it serves.
- **Lean.** Theorem 1 for finite groups (`lean/TheoremWplus.lean`, `lean/TheoremW.lean`), the answer to Question 3
  of Glasscock, Koutsogiannis and Richter (`lean/Recurrence.lean`), and Corollary 9 at the level of homomorphisms
  (`χ_c`, `χ` and `κ` are not defined there) with the lonely runner theorem for three speeds (Lemma 10;
  `lean/DistLiu.lean`) are formally verified, and checked locally (`lean/VERIFY_*.md`), not by continuous
  integration.
