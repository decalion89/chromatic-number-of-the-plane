Four colours are needed for every d = 11 (mod 12): the configurations and the checks
===================================================================================

notes/four_colours_11_mod_12.md proves by hand that for every positive integer d = 11 (mod 12) no character of the
group generated by an explicit finite set U of unit vectors of Q(sqrt d)^2 maps U into [1/3, 2/3]; by Theorem W
(notes/winding_lemma.md) the plane over Q(sqrt d) then needs four colours.

  d = 23 (mod 24):  U = G u G u1 u G conj(u1)                   with d < 21 * 5^(k-1)  (sharp)
  d = 11 (mod 24):  U = G u G u1 u G conj(u1) u G un            with 5^k > (2 sqrt10/3) n (n + d)

where G is the set of the 4(2k+1) rational unit vectors whose denominators divide 5^k, u_n = (n + i sqrt d)^2/(n^2 + d),
s = v_3(d + 1) and n = 1 + 2*3^(s+1) (any positive n = 3 mod 4 with n = 1 mod 3^(s+1) works).

Files
-----
structure_lemma.py   exact checks of the facts used in the proof of Proposition 1 (the shape of S_N, N = 5^k):
                     G_N = e rho^j; the bipartite point c*; the four 3-torsion points; the radius sqrt10/18 of P_1;
                     the distance sqrt2/6; and S_{5^k} itself by exact polygon clipping for k <= KPOLY.
                     usage: python3 structure_lemma.py [KMAX=6] [KPOLY=2]      (KPOLY=3 takes about 20 s)
family23.py          the configuration for d = 23 (mod 24): python3 family23.py d [k] -> in_fam_d_L.json
family11.py          the configuration for d = 11 (mod 24): python3 family11.py d [k|-] [n] [--milp]
                     -> in_f11_d_L.json; --milp runs the floating-point test of ../kapparel.py (SCIP)
limit.py             for a finite set of unit vectors Delta, decides whether G_N (Delta u {1}) is feasible for all
                     large N: by Proposition 1 and Lemma 5 of the note this asks for a character with values in
                     {1/3, 1/2, 2/3}, a finite computation in (Z/6)^4
cert_f23_d_kK.json.gz, cert_f11_d_kK.json.gz
                     exact certificates (../certify_w2.py; branch and bound with Farkas leaves) for the
                     configurations with 5^K, checked by ../check_w.py and by the independent integer-only checker:
                     d = 23 mod 24: d = 23, 47, 71, 95 (K = 2), 119, 143, ..., 311 (K = 3, every squarefree value);
                     d = 11 mod 24: d = 11, 35, 59 (K = 2), 83, 131, 155 (K = 3).
                     For d = 11 mod 24 these K are smaller than the proof needs; they are computer checks of
                     particular cases.

Tests: tests/test_winding_family.py.
