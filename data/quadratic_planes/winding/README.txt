Winding test for three colours (Lemma W) over Q(sqrt d)^2
==========================================================

Lemma W.  Let Gamma be an abelian group and S = -S a subset of Gamma \ {0}.  The Cayley graph Cay(Gamma, S) has a
proper 3-colouring if and only if some homomorphism xi : Gamma -> R/Z maps every s in S into the closed arc
[1/3, 2/3].

Proof sketch.  "If": colour g by floor(3 xi(g)) mod 3.  "Only if": in a 3-colouring c every edge step changes the
colour by +1 or -1 (mod 3); around any 4-cycle g, g+s, g+s+t, g+t these four signs sum to 0 (the sum is
0 mod 3 and lies in {-4, ..., 4} with the parity of 4, and the partial sums -2, 0, 2 are distinct mod 3), so the
winding (sum of signs)/3 of a closed walk depends only on its multiset of steps, not on the order or the base point
(this is the discrete winding number of Krebs and Sankar, arXiv:2410.11028).  Average the signs sigma(g, s) over the
subgroup generated by S with a translation-invariant mean: the averages f(s) in [-1, 1] satisfy
sum_j f(s_j) = 3 w(r) for every relation r = (s_1, ..., s_n) (sum s_j = 0), with w(r) an integer of the parity of n.  Then xi(s) = (f(s)/3 + 1)/2 is additive on relations, so it defines a
homomorphism on the subgroup generated by S, with values in [1/3, 2/3]; extend it to Gamma.

Consequences checked here: Payan's theorem (cube-like graphs are never 3-chromatic) and the exponent-4 case of
Krebs-Sankar follow at once; for distance graphs G(Z, D), chi <= 3 iff kappa(D) >= 1/3 (distgraph_test.py agrees
with Zhu's list of 4-chromatic 3-element sets for all D in [1, 24]); circ_test.py checks the lemma on 3888 random
finite abelian Cayley graphs.

For the plane over F = Q(sqrt d): U_D = unit vectors ((a + b sqrt d)/D, (c + e sqrt d)/D) (kappaD.units).  If no
character of Z U_D sends U_D into [1/3, 2/3], then Cay(Z U_D, U_D) is not 3-colourable, so (compactness)
chi(Q(sqrt d)^2) >= 4.

Files
-----
kappaD.py       unit vectors with denominator D; theta-space MILP (slow; kept for reference)
kapparel.py     the test in relation space: f_u in [1/3, 2/3], <r, f> integer for an LLL-reduced basis r of the
                integer relations among the units (SCIP through OR-tools; floating point, a guide only)
                usage: python3 kapparel.py d D [A] [time_limit_s]      (A = 1/3; A = 1/4 tests circular 4-colourings)
minimize.py     greedy deletion of units keeping the test infeasible: python3 minimize.py d D seed -> min_d_D_sSEED.json
certify_w2.py   exact certificate: branch and bound over the integer values z_j = <r_j, f>; every leaf carries a
                rational Farkas vector checked in exact arithmetic.  python3 certify_w2.py IN.json OUT.json
                (IN: {"d", "D", "units": [[a, b, c, e], ...]}, one unit per +- pair)
fastcert.py     the same with sampled branching candidates: python3 fastcert.py IN.json OUT.json [K]
check_w.py      independent checker (integers and fractions only; every failed check raises an error, so python -O
                checks the same, and floats are rejected): python3 check_w.py OUT.json -> VERIFIED ... or REJECTED

check_w_indep.py a second checker, written separately by a referee from the certificate format (integers and
                 fractions; python-flint for ranks): units, relations, every branch and leaf, the rank of the units,
                 whether the relations generate all relations, and whether U is all of U_D.
                 python3 check_w_indep.py CERT.json.gz ... ; check_w_indep.out is its output on the 26 stored
                 certificates (here and in family/)
